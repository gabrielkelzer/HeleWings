# 📖 SOBRE A HELÊWINGS V1 OFICIAL

## 📜 História

A **HeleWings v1** (ou *Asas de Helê*) é uma script cuja ideia de criação foi do **Gabriel Kelzer**.

Esta ferramenta é praticamente uma atualização da **Hele**, cujo desenvolvedor é o mesmo.

Vale destacar que na **HelêWings** o Gabriel Kelzer obteve ajuda de alguns membros da **KelzerBoy**.

# 📥 INSTALAÇÃO

## ➤ Primeiro Passo

Primeiro baixe o **Termux** e em seguida siga todas as instruções abaixo.

---

## 📂 [1] Permitir acesso aos arquivos

```bash
termux-setup-storage
```

---

## 🔄 [2] Atualizar repositórios

```bash
apt update
apt upgrade -y
```

---

## 📦 [3] Instalar o Git

```bash
pkg install git -y
```

---

## 🌐 [4] Baixar a Script

```bash
git clone https://github.com/HelexielKelzer/HeleWings
```

---

## 📁 [5] Entrando na pasta da Script e dando permissões

```bash
ls

cd HeleWings

chmod +x *

pkg install lolcat -y
```

---

## 🚀 [6] Iniciar a Script

```bash
. ./HeleWings.sh
```
